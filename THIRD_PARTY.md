# Bundled software

The two `installer/vendor/` directories contain unmodified standalone **esptool 5.4.0** executables published by Espressif, for macOS Apple Silicon and Intel. Each directory includes its upstream GPL-2.0-or-later license.

- Upstream project and release: https://github.com/espressif/esptool/releases/tag/v5.4.0
- Corresponding source: https://github.com/espressif/esptool/tree/v5.4.0
- Source archive: https://github.com/espressif/esptool/archive/refs/tags/v5.4.0.tar.gz

The installer invokes esptool as a separate program. esptool's own technical output and upstream project names are retained unchanged.

Markdown is used only on the package builder's computer to render the guide. Recipients do not install or download it.
